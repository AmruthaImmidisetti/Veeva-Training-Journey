# Java Object-Oriented Programming (OOP)

This folder contains Java programs and explanations covering the fundamental concepts of Object-Oriented Programming (OOP). It includes theoretical concepts, important points, and practical examples to understand Java OOP step by step.

## Topics Covered

### 1. Classes and Objects

Classes and objects are the basic building blocks of Java OOP. A class acts as a blueprint that defines properties (variables) and behaviors (methods), while an object is an instance of that class.

**Files:**
- [Classes and Objects - Explanation](01-Classes-and-Objects/README.md)
- [Student.java](01-Classes-and-Objects/Student.java)

### 2. Constructors and `this` Keyword

Constructors are special members used to initialize objects when they are created. The `this` keyword refers to the current object and helps access its variables, methods, and constructors.

**Files:**
- [Constructors and this - Explanation](02-Constructors-and-This/README.md)
- [StudentConstructor.java](02-Constructors-and-This/StudentConstructor.java)

### 3. Inheritance

Inheritance allows one class to acquire the properties and methods of another class. It promotes code reusability and supports relationships between parent and child classes.

**Files:**
- [Inheritance - Explanation](03-Inheritance/README.md)
- [SingleInheritance.java](03-Inheritance/SingleInheritance.java)
- [MultilevelInheritance.java](03-Inheritance/MultilevelInheritance.java)

### 4. Polymorphism

Polymorphism means many forms. It allows the same method name to perform different operations through method overloading and method overriding. Java supports compile-time and runtime polymorphism.

**Files:**
- [Polymorphism - Explanation](04-Polymorphism/README.md)
- [MethodOverloading.java](04-Polymorphism/MethodOverloading.java)
- [MethodOverriding.java](04-Polymorphism/MethodOverriding.java)

### 5. Encapsulation

Encapsulation is the process of combining data and methods within a single class while restricting direct access to data. It is commonly achieved using private variables and public getter and setter methods.

**Files:**
- [Encapsulation - Explanation](05-Encapsulation/README.md)
- [BankAccount.java](05-Encapsulation/BankAccount.java)

### 6. Abstraction

Abstraction focuses on hiding implementation details and exposing only essential functionality. Java achieves abstraction mainly through abstract classes and interfaces.

**Files:**
- [Abstraction - Explanation](06-Abstraction/README.md)
- [AbstractClassExample.java](06-Abstraction/AbstractClassExample.java)
- [InterfaceExample.java](06-Abstraction/InterfaceExample.java)

## How to Run Java Programs

1. Install the Java Development Kit (JDK).
2. Open the project in Eclipse or any Java IDE.
3. Alternatively, open a terminal in the directory containing the Java file.
4. Compile and execute the program:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the actual Java filename.
