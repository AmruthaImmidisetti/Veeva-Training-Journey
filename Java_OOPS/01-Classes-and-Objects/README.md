# Classes and Objects

Classes and Objects are the basic building blocks of Object-Oriented Programming (OOP) in Java.

## 1. Class

A class is a blueprint or template used to create objects. It defines the properties (variables) and behaviors (methods) that its objects can have.

**Components of a Class:**
- **Fields:** Variables that store object data.
- **Methods:** Functions that define the behavior of objects.
- **Constructors:** Special members used to initialize objects.

## 2. Object

An object is an instance of a class. It represents a real-world entity and contains its own values for instance variables.

**Characteristics of an Object:**
- **State:** Represented by its data or variables.
- **Behavior:** Represented by its methods.
- **Identity:** Distinguishes one object from another.

## 3. Creating Objects

- The `new` keyword is commonly used to create objects.
- A reference variable stores the reference to an object.
- Multiple objects can be created from the same class.
- Each object maintains its own instance variable values.

## 4. Accessing Class Members

- The dot (`.`) operator is used to access accessible fields and methods through an object reference.
- Instance variables belong to individual objects.
- Static variables and methods belong to the class and are shared at the class level.

## 5. Difference Between Class and Object

| Class | Object |
|---|---|
| Blueprint or template | Instance of a class |
| Defines properties and methods | Contains actual values and uses methods |
| Logical definition | Runtime entity |
| Declared using the `class` keyword | Commonly created using `new` |

## 6. Advantages

- Supports code reusability.
- Helps organize code into separate units.
- Represents real-world entities.
- Provides the foundation for encapsulation, inheritance and polymorphism.

## Key Points to Remember

- A class defines the structure of objects.
- An object is an instance of a class.
- Multiple objects can be created from one class.
- Each object has its own instance variables.
- Objects access their members using the dot operator.
- Static members are associated with the class rather than individual objects.
